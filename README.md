# PolyReco

Восстановление геометрии многогранников по наблюдаемым контурам.

## Продолжение на другом компьютере

Нужны Git, Git LFS и uv. Репозиторий содержит исходники, тесты, документы,
исходные данные всех пяти моделей и сохранённые результаты. Файлы `output/`
хранятся через Git LFS; исходные данные `data/` — в обычном Git.

```bash
git lfs install
git clone git@github.com:vkonov2/PolyReco.git
cd PolyReco
git lfs pull
uv sync --locked
uv run python -m unittest discover -s tests
```

Если репозиторий уже склонирован, сначала сохранить собственные локальные изменения,
затем выполнить `git pull --ff-only` и `git lfs pull`. Для проверки загруженных
результатов: `git lfs fsck`.

Текущее состояние: первый диагностический этап на `round` завершён; следующий шаг —
сравнение локальных окон и восстановления ребра по нескольким уровням Z.
Постановка, результаты, команды воспроизведения и следующий эксперимент сохранены
в [дорожной карте](docs/template_reconstruction_roadmap.md).

Основной viewer: `output/all_models_minima_cloud_distance_map.html`.
Он загружает данные по частям. Полный `output/minima_cloud_diagnostics.json`
предназначен для анализа кодом; его не нужно открывать в браузере.

Локальное окружение, Python-кэши и служебные файлы macOS не переносятся.
Новые файлы в `data/` и `output/` добавляются явно через `git add -f`;
уже сохранённые файлы остаются отслеживаемыми.
